## 解決したい課題

- どのような課題か: プロジェクト、工数、勤怠の情報を別々のツールから出力し、レポート作成時に手作業でまとめている。
- なぜ今取り組むのか: 根拠となる情報が未記録のため、関係者への確認が必要。
- 確認できている情報: 記入例として仮置きした仕事の流れ。現在値はまだ測定していない。
- 期待する結果: レポート作成の手間を減らし、より早く同じ基準で判断できるようにする。
