# 工数管理ダッシュボードの記入例

この例は、工数管理ダッシュボードの企画をHVEの流れへ当てはめたものです。文書の形とIDのつながりを示すための例であり、最新の市場調査や確認済みの要件ではありません。

## IDのつながりの例

| 段階 | 文書またはIDの例 |
| --- | --- |
| 課題 | プロジェクト、工数、勤怠の出力データを手作業でまとめている |
| 調べること | `RQ-001`: 中規模の開発組織に合う連携と分析の方法は何か |
| 調査結果 | `INSIGHT-001`: 調査後に記入する仮のID |
| KPI | `KPI-001`: レポート準備時間 |
| 要件 | `REQ-001`: 決められたCSV形式を取り込み、エラー内容を表示する |
| 技術判断 | `ADR-001`: 要件の確認後に記入する仮のID |
| 実装タスク | `TASK-001`: 1種類のCSVを取り込む処理を最初から最後まで作る |
| テスト | `TEST-001`: 正しい行は受け付け、不正な行には直し方が分かるエラーを返す |

[プロジェクト概要の例](./project-brief.md)と[IDのつながりの例](./traceability-matrix.md)も確認してください。判断に使う前に、仮の内容を実際の情報へ置き換えます。
